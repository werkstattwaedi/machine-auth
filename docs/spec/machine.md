# Machine terminal

Unlocking a machine at its machine terminal, and the permissions a machine
requires and a person holds. Where the team grants them is in
[admin.md](admin.md) (ADM-16), how a course grants them in
[courses.md](courses.md) (CRS); what a permission does for the price of a
badge is MEM-14. Terms: see the [glossary](README.md#glossary).

## Permissions

- **MAC-1** A machine terminal unlocks a machine only for a badge whose account holds every permission the machine requires — for good (MAC-4) or temporarily from a course (CRS-11) — an admin's account included, except a badge it lets in again under MAC-3; a machine that requires none asks for none. — #154, #842, #843
- **MAC-4** A person holds a permission for good when an admin grants it — to anyone, themselves included — or the close of a course grants it (CRS-14), and then until an admin removes it; a temporary permission comes only from a course (CRS-11). — #512, #842, #843
- **MAC-3** For up to 4 h after the server last let a badge in at a machine terminal, that terminal lets the same badge in again without asking the server, so a refusal the server would give in that time — such as for a permission removed (MAC-4) or a temporary one past its window (CRS-11), a deactivated badge or an open visit from an earlier day — does not stop it there. — #843

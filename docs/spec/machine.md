# Machine terminal

Unlocking a machine at its machine terminal, and the permissions a machine
requires and a person holds. Where the team grants them is in
[admin.md](admin.md) (ADM-16); what a permission does for the price of a
badge is MEM-14. Terms: see the [glossary](README.md#glossary).

## Permissions

- **MAC-1** A machine terminal unlocks a machine only for a badge whose account holds every permission the machine requires, an admin's account included, except a badge it lets in again under MAC-3; a machine that requires none asks for none. — #154, #843
- **MAC-2** Only an admin grants or removes a person's permissions, and a granted permission holds until an admin removes it. — #512
- **MAC-3** For up to 4 h after the server last let a badge in at a machine terminal, that terminal lets the same badge in again without asking the server, so a refusal the server would give in that time — such as for a permission the account no longer holds (MAC-2), a deactivated badge or an open visit from an earlier day — does not stop it there. — #843
